# Mass Central Trail Stays

Prototype for the Mass Central Rail Trail lodging and trip-planning platform RFP.

Three design concepts, one codebase:

- `/trailhead/` - map-first outdoors app look
- `/meadow/` - clean New England tourism look
- `/depot/` - rail-heritage look

Source is `index.html` + `styles.css` + `data.js` + `app.js` (+ `theme-*.css`). Run `py build.py` to rebuild the single-file concept pages. All lodging properties are fictional and trail mileage is approximate.
